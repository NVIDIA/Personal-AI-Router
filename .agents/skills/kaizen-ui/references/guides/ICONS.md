# Icons

As part of KUI we use the NVIDIA Brand Assets icons for our components.

## Usage

Preferred: these icons are available as React components that render SVGs in the `@nv-brand-assets/react-icons-inline` package.

```tsx
import { ChevronDown } from "@nv-brand-assets/react-icons-inline";

// default is outline
<ChevronDown />

// filled/solid icon is available as a variant, prefer for smaller icons
<ChevronDown variant="fill" />
```

Some projects might be using the `@nv-brand-assets/react-icons` or `@nv-brand-assets/react-icons-web-font` packages for hosted icons, which provide a `NvidiaGUIIcon` React component that accepts an `iconName` prop (kebab-case version of the icon name).

```tsx
import { NvidiaGUIIcon } from "@nv-brand-assets/react-icons";

// default is still outline
<NvidiaGUIIcon iconName="chevron-down" />

// still accepts the "variant" prop for solid icons
<NvidiaGUIIcon iconName="chevron-down" variant="fill" />
```
