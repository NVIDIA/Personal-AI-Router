# Dropdown

Use Dropdowns to allow users to select one or multiple options, navigate through links, or take
actions. Dropdowns are often used for navigation, filters, or contextual actions.

## Examples

### Basic Dropdown With Links

```tsx
<Dropdown
    items={[
        { children: 'Item 1', href: '/item-1' },
        { children: 'Item 2', href: '/item-2' },
        { children: 'Item 3', href: '/item-3' }
    ]}
    // replace default anchor with a custom link component using the renderLink prop
    // renderLink={(item) => <Link href={item.href}>{item.children}</Link>}
>
    Actions
</Dropdown>
```

### Basic Dropdown With Handlers

Use when you need a simple list of actions triggered from a button.

```tsx
<Dropdown
    items={[
        { children: 'Edit', onSelect: handleSelect },
        { children: 'Duplicate', onSelect: handleSelect },
        { children: 'Delete', danger: true, onSelect: handleSelect }
    ]}
>
    Actions
</Dropdown>
```

### With Item Select Callback Dropdown

Use the aggregate onItemSelect callback when every item shares the same selection logic — easier to wire into a router, analytics, or a reducer than per-item onSelect handlers. Reach for per-item onSelect when each item needs distinct behavior.

```tsx
<Dropdown
    items={[
        { children: 'Edit', value: 'edit' },
        { children: 'Duplicate', value: 'duplicate' },
        { children: 'Delete', value: 'delete', danger: true }
    ]}
    onItemSelect={handleItemSelect}
>
    Actions
</Dropdown>
```

### With Icons Dropdown

Use slotStart and slotEnd to add leading or trailing icons that reinforce each item's meaning.

```tsx
<Dropdown
    items={[
        {
            children: 'Edit',
            slotStart: <Document />,
            onSelect: handleSelect
        },
        {
            children: 'Duplicate',
            slotStart: <CopyDoc />,
            slotEnd: <InfoCircle />,
            onSelect: handleSelect
        },
        {
            children: 'Delete',
            danger: true,
            slotStart: <Trash />,
            onSelect: handleSelect
        }
    ]}
>
    Actions
</Dropdown>
```

### With Sections Dropdown

Use when dropdown items are logically grouped into categories that benefit from visual separation.

```tsx
<Dropdown
    items={[
        {
            slotHeading: 'Navigation',
            items: [
                { children: 'Dashboard', onSelect: handleSelect },
                { children: 'Settings', onSelect: handleSelect }
            ]
        },
        {
            slotHeading: 'Account',
            items: [
                { children: 'Profile', onSelect: handleSelect },
                { children: 'Sign Out', danger: true, onSelect: handleSelect }
            ]
        }
    ]}
>
    Menu
</Dropdown>
```

### With Sub Menu Dropdown

Use when certain actions have nested options that should be discoverable without cluttering the main list.

```tsx
<Dropdown
    items={[
        { children: 'Cut', onSelect: handleSelect },
        { children: 'Copy', onSelect: handleSelect },
        {
            kind: 'sub',
            children: 'Share',
            items: [
                { children: 'Email', onSelect: handleSelect },
                { children: 'Slack', onSelect: handleSelect }
            ]
        }
    ]}
>
    Edit
</Dropdown>
```

### With Dividers Dropdown

Insert a divider entry to visually separate destructive or unrelated actions inside a flat list.

```tsx
<Dropdown
    items={[
        { children: 'Open', onSelect: handleSelect },
        { children: 'Open in New Tab', onSelect: handleSelect },
        { kind: 'divider' },
        { children: 'Rename', onSelect: handleSelect },
        { children: 'Move', onSelect: handleSelect },
        { kind: 'divider' },
        { children: 'Delete', danger: true, onSelect: handleSelect }
    ]}
>
    File
</Dropdown>
```

### Checkbox Dropdown

Use when the user needs to toggle multiple independent options from a single dropdown.

```tsx
<Dropdown
    items={[
        {
            children: 'Show Labels',
            kind: 'checkbox',
            defaultChecked: true
        },
        {
            children: 'Show Tooltips',
            kind: 'checkbox'
        },
        {
            children: 'Compact Mode',
            kind: 'checkbox'
        }
    ]}
>
    View Options
</Dropdown>
```

### Radio Dropdown

Use when the user must pick exactly one option from a group of mutually exclusive choices.

```tsx
<Dropdown
    items={[
        {
            kind: 'radio',
            name: 'theme',
            slotHeading: 'Theme',
            defaultValue: 'auto',
            items: [
                { children: 'Auto', value: 'auto' },
                { children: 'Light', value: 'light' },
                { children: 'Dark', value: 'dark' }
            ]
        }
    ]}
>
    Theme
</Dropdown>
```

### Check Radio Dropdown

Set radioKind to 'check' when you want a single checkmark on the selected option instead of radio dots — common for compact filter or theme pickers.

```tsx
<Dropdown
    items={[
        {
            kind: 'radio',
            radioKind: 'check',
            name: 'status',
            slotHeading: 'Status',
            defaultValue: 'ready',
            items: [
                { children: 'Ready', value: 'ready' },
                { children: 'Pending', value: 'pending' },
                { children: 'Completed', value: 'completed' }
            ]
        }
    ]}
>
    Status
</Dropdown>
```

### Mixed Dropdown

Combine action items, checkbox toggles, and radio groups in a single dropdown by nesting them in sections.

```tsx
<Dropdown
    items={[
        {
            slotHeading: 'Actions',
            items: [
                { children: 'Edit', onSelect: handleSelect },
                { children: 'Duplicate', onSelect: handleSelect },
                { children: 'Delete', danger: true, onSelect: handleSelect }
            ]
        },
        {
            slotHeading: 'Settings',
            items: [
                {
                    kind: 'checkbox',
                    children: 'Show notifications',
                    defaultChecked: true
                },
                {
                    kind: 'checkbox',
                    children: 'Auto-save',
                    defaultChecked: false
                }
            ]
        },
        {
            kind: 'radio',
            slotHeading: 'Theme',
            name: 'mixed-theme',
            defaultValue: 'system',
            items: [
                { children: 'System', value: 'system' },
                { children: 'Light', value: 'light' },
                { children: 'Dark', value: 'dark' }
            ]
        }
    ]}
>
    More
</Dropdown>
```

### Filterable Dropdown

Use when the dropdown contains many items and the user benefits from searching to find their selection quickly.

```tsx
<Dropdown
    filterable
    items={[
        { children: 'United States', onSelect: handleSelect },
        { children: 'Canada', onSelect: handleSelect },
        { children: 'United Kingdom', onSelect: handleSelect },
        { children: 'Germany', onSelect: handleSelect },
        { children: 'Japan', onSelect: handleSelect }
    ]}
>
    Select Country
</Dropdown>
```

### Icon Only Trigger Dropdown

Use an icon child with showChevron={false} for kebab/overflow menus where space is constrained. Always supply an aria-label.

```tsx
<Dropdown
    showChevron={false}
    aria-label="More actions"
    items={[
        { children: 'Edit', onSelect: handleSelect },
        { children: 'Duplicate', onSelect: handleSelect },
        { children: 'Delete', danger: true, onSelect: handleSelect }
    ]}
>
    <MenuIcon />
</Dropdown>
```

### Size Dropdown

Match the trigger size to the surrounding controls. Pass density to override the menu's default density independently from the trigger size.

```tsx
<Flex gap="2" align="center" wrap="wrap">
    <Dropdown size="small" items={['Item 1', 'Item 2', 'Item 3']}>
        Small
    </Dropdown>
    <Dropdown size="medium" items={['Item 1', 'Item 2', 'Item 3']}>
        Medium
    </Dropdown>
    <Dropdown size="large" items={['Item 1', 'Item 2', 'Item 3']}>
        Large
    </Dropdown>
</Flex>
```

### Positioning Dropdown

Combine `side` (`top` | `bottom` | `left` | `right`) and `align` (`start` | `center` | `end`) to override the default `bottom`/`start` placement when the menu would clip against a scroll container or viewport edge.

```tsx
<Dropdown side="right" align="end" items={['Item 1', 'Item 2', 'Item 3']}>
    Open
</Dropdown>
```

### Server Actions Dropdown

Wrap composed primitives in a <form> and pass formAction/formMethod on each DropdownItem so the menu submits to different endpoints without JavaScript.

```tsx
<form>
    <DropdownRoot>
        <DropdownTrigger>Task Actions</DropdownTrigger>
        <DropdownContent>
            <DropdownItem formAction="/api/tasks/complete" formMethod="post">
                Mark as Complete
            </DropdownItem>
            <DropdownItem formAction="/api/tasks/reassign" formMethod="post">
                Reassign
            </DropdownItem>
            <DropdownItem danger formAction="/api/tasks/delete" formMethod="post">
                Delete Task
            </DropdownItem>
        </DropdownContent>
    </DropdownRoot>
</form>
```

### Composed

Use composed primitives when you need full control over the dropdown trigger, content, and item rendering.

```tsx
<DropdownRoot>
    <DropdownTrigger asChild>
        <Button>Open</Button>
    </DropdownTrigger>
    <DropdownContent>
        <DropdownItem
        // onSelect={handleSelect}
        >
            Item 1
        </DropdownItem>
        <DropdownItem
        // onSelect={handleSelect}
        >
            Item 2
        </DropdownItem>
        <DropdownItem
            danger
            // onSelect={handleSelect}
        >
            Delete
        </DropdownItem>
    </DropdownContent>
</DropdownRoot>
```
