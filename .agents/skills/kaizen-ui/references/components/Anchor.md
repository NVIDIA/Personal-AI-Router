# Anchor

Also known as: Link

A styled anchor element that provides consistent link styling across applications.

## Examples

### Basic Anchor

```tsx
<Flex gap="2">
    <Anchor href="/" kind="inline">
        Inline
    </Anchor>
    <Anchor href="/" kind="standalone">
        Standalone
    </Anchor>
</Flex>
```

### Custom Link Component

Use asChild to render framework specific link components with our styling

```tsx
<Anchor asChild>
    <NextLink href="/">Home</NextLink>
</Anchor>
```

### Disabled Anchor

A disabled anchor will render as a span instead of an anchor tag

```tsx
<Anchor disabled href="/">
    Disabled Link
</Anchor>
```

### As Button

Render Anchor as a button for non-navigation tasks

```tsx
<Anchor asChild>
    <button onClick={() => console.log('Button clicked')} type="button">
        View Details
    </button>
</Anchor>
```
